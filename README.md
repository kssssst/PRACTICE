## Реализованная функциональность задания 1.3

Проект содержит Windows-службу `TrayAppService`, RPC-клиент и Win32 GUI.


Служба:
- выполняет вход через `POST https://localhost:8443/auth/login`;
- хранит `accessToken`, `refreshToken` и лицензионный тикет только в оперативной памяти;
- обновляет JWT через `/auth/refresh` с учетом срока действия токенов;
- выполняет выход через `/auth/logout` и очищает токены вместе с лицензией;
- проверяет лицензию через `/api/licenses/check`;
- активирует продукт через `/api/licenses/activate`;
- обновляет лицензионный тикет по `ttlMillis`;
- через RPC отдает клиенту только безопасную информацию: email, наличие лицензии, блокировку и дату истечения.

GUI:
- при запуске получает текущего пользователя через RPC;
- если входа нет, показывает форму входа и блокирует антивирусную функциональность;
- после входа показывает email и проверяет лицензию;
- если лицензии нет, показывает форму активации;
- после успешной активации показывает дату истечения и разблокирует функциональность;
- периодически опрашивает службу и обновляет состояние на главном экране.

Настройки службы по умолчанию:
- `TRAYAPP_SERVER_URL=https://10.211.55.1:8443`
- `TRAYAPP_PRODUCT_ID=1`
- `TRAYAPP_ALLOW_INSECURE_TLS=1`

Если сервер запущен на другом адресе или продукт имеет другой ID, задайте эти переменные окружения для службы/системы перед запуском.
Для учебного self-signed HTTPS сертификата проверка TLS отключена по умолчанию. Для строгой проверки задайте `TRAYAPP_ALLOW_INSECURE_TLS=0`.

Сборка на Windows из Developer PowerShell:

```bat
cmake -S . -B build -G "Visual Studio 17 2022"
cmake --build build --config Release
```

После сборки запустите `install_service.bat` из папки с `TrayService.exe` и `TrayApp.exe` от имени администратора.
